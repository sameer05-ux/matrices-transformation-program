# Matrices Transformation Program

## Description
A command-line application built in Python that allows users to enter matrices, apply standard 2D transformations to them when possible, and display them graphically using the matplotlib library.

## Features
- Allows users to enter matrix values through an interactive console interface.
- Allows users to apply standard 2D transformations (rotation and scaling) to matrices.
- Uses comprehensive input validation to check matrix dimensions, handle invalid characters, and prompt users to re-enter values without crashing the program.
- Allows users to graphically plot their matrix as a set of coordinates using matplotlib.
- Allows users to numerically view their current matrices through the command line.

## Prerequisites
- Requires Python (preferably version 3.x)
- Requires the `matplotlib` library (`pip install matplotlib`)
